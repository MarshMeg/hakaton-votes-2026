# Как запустить проект локально

Самый простой способ — Docker: одна команда поднимает сервер, базу и хранилище картинок,
дальше приложение открывается в браузере. Подробная настройка окружения для разработки —
в [docs/local-setup.md](docs/local-setup.md).

## 1. Что нужно

- [Docker](https://docs.docker.com/get-docker/) с Compose v2 (команда `docker compose`).
  На Windows — Docker Desktop.
- Свободные порты **8000**, **9000** и **9001**.
- Git (или скачайте архив репозитория: Code → Download ZIP).

## 2. Запуск

```bash
git clone https://github.com/MarshMeg/hakaton-votes-2026.git
cd hakaton-votes-2026
docker compose up --build
```

Первый запуск занимает несколько минут (скачиваются образы и собирается сервер). Готово, когда
в логе появилось `Booting worker`. Файл `.env` не нужен — все настройки по умолчанию уже заданы.

При старте сервер сам применяет миграции, загружает словарь (11 тем, 85 слов, картинки
и озвучка), собирает офлайн-снимок для телефона и создаёт администратора.

## 3. Что открыть

| Адрес | Что там | Вход |
|---|---|---|
| http://localhost:8000 | приложение | зарегистрируйтесь в окне «Ты здесь впервые?» |
| http://localhost:8000/admin | админка: словарь, картинки, аудио | `admin` / `admin12345` |
| http://localhost:9001 | консоль MinIO (хранилище файлов) | `minioadmin` / `minioadmin` |

Приложение сделано для телефона, поэтому в браузере удобнее смотреть в мобильном режиме:
**F12 → Ctrl+Shift+M** (Chrome, Edge, Firefox) и выбрать любой телефон.

Что посмотреть:
- **Обучение** — карточки слов по темам, кнопка 🔊 проигрывает произношение
- **Игры** — шесть игр и «Трудные слова» (появляются после ошибок)
- **Профиль** — статистика и «Отчёт об успехах» для родителя или учителя
- **Настройки** — тема (как в телефоне / светлая / тёмная), звук, уведомления, геолокация

## 4. Остановить

```bash
docker compose down        # остановить, данные сохраняются
docker compose down -v     # остановить и удалить все данные (аккаунты, прогресс)
```

## 5. Android-приложение

Готовый APK (Android 8.0+):
https://github.com/MarshMeg/hakaton-votes-2026/releases/latest/download/votes.apk

Он подключается к нашему серверу, ничего настраивать не нужно. При первом запуске нужен
интернет (вход в аккаунт и загрузка слов), дальше приложение работает и без сети.

Чтобы телефон работал с **локальным** сервером из шага 2, APK нужно собрать самому:
1. Узнайте IP компьютера в локальной сети (например `192.168.0.10`), телефон должен быть
   в той же Wi-Fi сети.
2. Создайте `.env` из примера и укажите в нём этот IP, затем перезапустите `docker compose up`:
   ```bash
   cp .env.example .env
   ```
   ```
   DJANGO_CSRF_TRUSTED_ORIGINS=http://localhost:8000,http://192.168.0.10:8000
   S3_PUBLIC_DOMAIN=192.168.0.10:9000/votes-media
   ```
3. Соберите APK (нужны Flutter и Android SDK, установка — в
   [docs/local-setup.md](docs/local-setup.md#4-android-приложение-только-тем-кто-работает-с-mobile)):
   ```bash
   cd mobile
   mise run setup
   mise exec -- flutter build apk --release --dart-define=SERVER_URL=http://192.168.0.10:8000
   ```
   Готовый файл: `mobile/build/app/outputs/flutter-apk/app-release.apk`.

В эмуляторе Android проще: `cd mobile && mise run dev` — он сам подключается к
`http://10.0.2.2:8000` (это `localhost` компьютера).

## 6. Без Docker

Нужен [mise](https://mise.jdx.dev) — он сам поставит Python 3.12, uv и Tailwind:
```bash
cd backend
mise trust && mise install
mise run setup     # зависимости, миграции, словарь (база — SQLite)
mise run dev       # http://localhost:8000
```
Администратор в этом режиме не создаётся автоматически:
`mise exec -- uv run python manage.py createsuperuser`.

## Если что-то не так

| Проблема | Что делать |
|---|---|
| `port is already allocated` | порт 8000, 9000 или 9001 занят — остановите программу, которая его держит |
| Нет картинок у слов | MinIO ещё запускается — подождите и обновите страницу |
| После обновления кода ничего не изменилось | `docker compose up --build` (с `--build`) |
| Хочется начать с чистого листа | `docker compose down -v`, затем снова `docker compose up --build` |
| Телефон не видит локальный сервер | проверьте IP, одну Wi-Fi сеть и что брандмауэр пропускает порты 8000 и 9000 |
